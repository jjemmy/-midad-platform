# مداد MIDAD — منصة التخطيط الإعلامي وصناعة المحتوى

> لكل كلمة أثر

منصة تفاعلية (صفحة واحدة) لبناء الحملات الإعلامية وتوليد الأوامر الموجهة (Prompts) للذكاء الاصطناعي،
مع تحديث حي للمنصات والأوامر حسب الحدث والموضوع والمصدر واللغة والجمهور المستهدف.

## المحتويات

| المسار | الوصف |
| --- | --- |
| `public/index.html` | واجهة المنصة الكاملة (HTML + Tailwind CDN + JavaScript) |
| `public/assets/midad-logo.png/.webp` | شعار مداد الرسمي بخلفية شفافة |
| `public/assets/rpt-regular/bold.woff2` | خط RPT المعتمد للهوية (عربي + لاتيني) |
| `public/assets/favicon.png` + `favicon-48.png` | أيقونة الموقع (شعار M/AI فضي على كحلي) |
| `public/assets/apple-touch-icon.png` | أيقونة الشاشة الرئيسية لـ iOS |
| `public/assets/icon-mark.png` | شعار M/AI بخلفية شفافة للاستخدامات الأخرى |
| `server.js` | خادم ملفات ثابتة بدون أي اعتماديات خارجية (Node.js فقط) |
| `scripts/version-assets.mjs` | يبصم روابط الأصول ببصمة محتواها لمنع الكاش القديم |
| `nixpacks.toml` | إعدادات البناء (Node.js 20) |
| `railway.json` | إعدادات النشر على Railway (أمر التشغيل + فحص الصحة) |

## المزايا

- ألوان الواجهة مبنية على أزرق الشعار (`#6BADFF`) بمقياس كامل من 50 إلى 900.
- **الوضع النهاري افتراضياً** مع زر تبديل للوضع الليلي، ويُحفظ الاختيار في المتصفح ويُطبّق قبل أول رسم للصفحة (بدون وميض).
- 6 تبويبات: نظرة عامة، مكونات الحملة الـ 5، خطة المحتوى والأوامر، توظيف الذكاء الاصطناعي، معايير التقييم الـ 8، بناء الخطة التفاعلي.
- توليد 6 أوامر موجهة (Role Prompting) تتحدث آلياً حسب المدخلات.
- اقتراح المنصات النشطة تلقائياً حسب الجمهور (السعودي / العربي / الغربي / الفارسي).
- نسخ الأوامر بنقرة واحدة + حفظ مسودة الخطة محلياً في المتصفح + طباعة/تصدير.

## التشغيل محلياً

المتطلبات: Node.js 20 أو أحدث. لا توجد أي حزم للتثبيت.

```bash
npm start
# أو
node server.js
```

ثم افتح: http://localhost:8080

لتغيير المنفذ:

```bash
PORT=3000 npm start
```

## النشر على Railway

1. ادخل على [railway.app](https://railway.app) واختر **New Project** ← **Deploy from GitHub repo**.
2. اختر المستودع `jjemmy/-midad-platform` والفرع المطلوب.
3. Railway يبني عبر Nixpacks (محدد في `railway.json`) ويشغّل `npm start` — لا حاجة لأي إعداد إضافي.
4. من تبويب **Settings** ← **Networking** اضغط **Generate Domain** واختر المنفذ `8080`.

### متغيرات البيئة

| المتغير | الوصف | الافتراضي |
| --- | --- | --- |
| `PORT` | المنفذ — الافتراضي `8080` ليطابق منفذ الدومين، وتستطيع Railway تجاوزه | `8080` |
| `HOST` | عنوان الاستماع | `0.0.0.0` |

لا يحتاج المشروع أي مفاتيح أو أسرار.

### فحص الصحة (Health Check)

المسار `/healthz` يعيد استجابة JSON ويُستخدم من Railway للتأكد من جاهزية الخدمة:

```json
{ "status": "ok", "service": "midad-platform", "uptime": 12.34 }
```

### النشر عبر Railway CLI (اختياري)

```bash
npm i -g @railway/cli
railway login
railway link
railway up
```

## تحديث الأصول (الشعار / الخط / الأيقونة)

روابط الأصول مبصومة ببصمة محتواها (`midad-logo.webp?v=2a760bbc`)، لذلك:

- **الملف المتغيّر** يصل للمتصفح فوراً لأن رابطه تغيّر.
- **الملف الثابت** يبقى في الكاش ولا يُحمّل مجدداً.

بعد أي تعديل داخل `public/assets` شغّل:

```bash
npm run version-assets
```

يعيد حساب البصمات ويحدّث `public/index.html` تلقائياً. سياسة الكاش في الخادم:

| النوع | الترويسة |
| --- | --- |
| `index.html` | `no-cache` — يُراجَع في كل طلب فيظهر النشر فوراً |
| أصل مبصوم بـ `?v=` | `max-age=31536000, immutable` |
| أصل غير مبصوم | `max-age=300` + `ETag` |

وكل الاستجابات تحمل `ETag` فتعيد `304` عندما تكون النسخة لدى المتصفح محدثة.
